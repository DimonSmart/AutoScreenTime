# AutoScreenTime.Poc — локальный эксперимент для Windows

Консольное приложение на C# / .NET 10. **Не является готовым родительским контролем.**
Оно только раз в минуту (или реже, если вывод моделей медленный) делает наблюдение,
передаёт скриншот одной активной области экрана модели Ollama, отдаёт её краткое описание
текстовому классификатору и записывает результат `-1/0/+1` в консоль и JSONL.

## Требования

- Windows 10/11 и .NET 10 SDK.
- Ollama на `http://127.0.0.1:11434`.
- Установленные модели:

```powershell
ollama pull qwen3-vl:8b
ollama pull gpt-oss:20b
ollama list
```

Вместо Qwen можно использовать `llama3.2-vision:11b`:

```powershell
ollama pull llama3.2-vision:11b
```

## Запуск

Запускать **из той же интерактивной Windows-сессии, экран которой нужно анализировать**.
Для демонстрации от имени своего пользователя, не от имени LocalSystem и не как Windows Service.
Права администратора не нужны. Остановить можно `Ctrl+C`.

```powershell
dotnet run --project .\AutoScreenTime.Poc.csproj -- --once
dotnet run --project .\AutoScreenTime.Poc.csproj -- --interval 60
dotnet run --project .\AutoScreenTime.Poc.csproj -- --vision llama3.2-vision:11b --once
dotnet run --project .\AutoScreenTime.Poc.csproj -- --save-screenshots --once
```

Данные по умолчанию пишутся в `./activity.jsonl`: время, PID и имя процессов текущей
сессии, активное окно, простая оценка бездействия, краткая интерпретация экрана,
оценка, объяснение, латентность. По умолчанию изображения **не сохраняются**.
При `--save-screenshots` PNG будут лежать в `screenshots` рядом с JSONL.
Содержимое логов может раскрывать личные сведения (например, заголовки окон): используйте
свою тестовую учётную запись и удалите данные после эксперимента.

## Интерпретация результата

- `+1` — обнаружена достаточно явная учебная/созидательная деятельность.
- `-1` — обнаружена достаточно явная развлекательная деятельность.
- `0` — нейтрально или недостаточно данных. `unknown` явно обозначает неопределённость.

**Это оценка одного снимка, а не достоверная история минуты.** `confidence` — самооценка
модели, не калиброванная статистическая вероятность. Никакие минуты не начисляются
и не списываются; блокировка не реализована.

## Ограничения

- .NET SDK/Windows/Ollama не доступны в среде, где готовился пример, поэтому реальная
  Windows-сборка, захват дисплея и качество inference здесь не проверялись.
- Активный монитор, а не все дисплеи; обычный desktop, не защищённый Winlogon/UAC.
- Возможны пустые/чёрные кадры из DRM-видео, во время блокировки и в некоторых графических приложениях.
- После долгого inference следующий снимок начинается без «догоняющей» серии: снимки не чаще раза в 60 с,
  но некоторые интервалы будут больше минуты.
- Список процессов относится только к текущей интерактивной сессии и может пропускать
  защищённые/быстро завершающиеся процессы. Командные строки процессов не читаются.
- Screenshot не гарантирует знание истинной активности за прошлые 60 секунд; модель может ошибаться,
  а текст на экране потенциально содержит prompt injection.
- Оценка `+1` не является автоматически «+1 минута бонуса». Привязка классов к бюджету — отдельное решение.

## Проверка гипотезы

Запустите по 5-10 наблюдений для: чтения PDF, редактирования домашней работы,
образовательного видео, развлекательного видео, игры, соцсетей, смешанных вкладок,
неясных окон, экрана блокировки, бездействия. Отмечайте вручную ожидаемую метку и
сравнивайте с `score`, анализируйте ошибочные `+1` и время inference.
