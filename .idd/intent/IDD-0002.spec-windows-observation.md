# IDD-0002.spec-windows-observation

## Intent

Получать ограниченный по объёму снимок деятельности текущей пользовательской сессии Windows с достаточным контекстом для исследования классификации.

## Related Specifications

- IDD-0001 — среда и границы прототипа.
- IDD-0003 — использование собранного контекста.
- IDD-0004 — расписание наблюдений.
- IDD-0005 — конфиденциальность и хранение.
- IDD-0006 — исследование качества исходных данных.

## Behavior

Каждое наблюдение имеет временную метку. Определяются активное окно и монитор, на котором оно находится; снимается изображение этого монитора. Для первой версии достаточно одного монитора на наблюдение.

Собираются доступные PID и имя активного процесса, заголовок окна, идентификатор пользовательской сессии, список PID и имён процессов этой сессии и время с последнего ввода пользователя. Недоступность отдельных метаданных не должна аварийно завершать приложение. Процессы, завершившиеся во время чтения или недоступные по правам, пропускаются.

Скриншот — основной источник семантических признаков. Заголовок и список процессов служат дополнительным контекстом: фоновая игра не доказывает, что пользователь играет. Отсутствие ввода само по себе не доказывает отсутствие полезной деятельности: чтение и лекция возможны без мыши и клавиатуры.

Заблокированный экран, недоступный рабочий стол, защищённая поверхность, ошибка захвата, пустой или некорректный кадр обрабатываются без выдуманной категории. Допустимый результат — `unknown` и `0`. Если блокировка или отсутствие активной сессии достоверно известны, желательно фиксировать это отдельно.

## Product-Significant Architecture And Constraints

Разрешается уменьшать изображение с сохранением пропорций. Ограничение 1920×1200 — предложенная исследовательская настройка, а не утверждённый оптимум: чрезмерное уменьшение ухудшает читаемость мелкого текста.

Сбор ограничен текущей пользовательской сессией и данными по IDD-0005. Аргументы командной строки процессов, открытые файлы и содержимое памяти для первого эксперимента не нужны.

## Non-Goals

Непрерывное видео, одновременный захват всех мониторов, доказательство чтения по статическому изображению, автоматическое распространение одного снимка на весь интервал между наблюдениями.

## Acceptance Criteria

1. Снимается монитор активного окна, включая сценарий нескольких подключённых мониторов.
2. Контекст включает доступные сведения активного окна, процессы текущей сессии и длительность бездействия.
3. Недоступный процесс или закрывшееся окно не обрушает приложение.
4. Недоступный экран не превращается в полезную или развлекательную деятельность.

## Verification

Проверить выбор монитора, изоляцию списка процессов по сессии, доступные метаданные и бездействие. Проверить гонки с закрытием окна и завершением процесса, отказ доступа, заблокированный рабочий стол и некорректный кадр. Отдельно проверить сценарий чтения без ввода и игру в фоне при работе с другим окном.
